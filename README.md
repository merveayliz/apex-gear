## 📖 Proje Hakkında / About

**TR:** Apex Gear, kullanıcı deneyimi ve estetik ön planda tutularak tasarlanmış modern bir e-ticaret arayüzüdür. Ziyaretçilerin ürünleri kolayca inceleyebileceği, dinamik etkileşimlerle akıcı bir alışveriş deneyimi yaşayabileceği şekilde kurgulanmıştır.

**EN:** Apex Gear is a modern e-commerce interface designed with a focus on user experience and aesthetics. It is structured to allow visitors to easily explore products and enjoy a seamless shopping experience with dynamic interactions.

---

## ✨ Öne Çıkan Özellikler / Key Features

- 🛍️ **Ürün Kataloğu / Product Catalog:** Modern kart yapısı, detaylı ürün görselleri ve kategori geçişleri.
- 📱 **Tam Mobil Uyumluluk / Fully Responsive:** Masaüstü, tablet ve mobil cihazlarda sorunsuz çalışan esnek UI/UX tasarımı.
- ⚡ **Dinamik Etkileşimler / Dynamic Interactions:** JavaScript (ES6+) altyapısıyla güçlendirilmiş akıcı sayfa içi geçişler ve ürün filtreleme.
- 🎨 **Modern Tasarım / Modern UI:** Koyu tema estetiği, göz yormayan renk paleti ve *Plus Jakarta Sans* / *Cinzel Decorative* tipografisi.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **İkonlar & Fontlar:** FontAwesome, Google Fonts (*Cinzel Decorative* & *Plus Jakarta Sans*)
* **Dağıtım / Hosting:** GitHub Pages
