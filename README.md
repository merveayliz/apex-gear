## 📖 Proje Hakkında / About

**TR:** Apex Gear, kullanıcı deneyimi ve estetik ön planda tutularak tasarlanmış, modern bir e-ticaret ve performans ekipmanları arayüzüdür. Ziyaretçilerin ürünleri kolayca inceleyebileceği, kategori filtrelemeleri yapabileceği ve akıcı bir alışveriş deneyimi yaşayabileceği şekilde kurgulanmıştır.

**EN:** Apex Gear is a modern e-commerce and performance equipment interface designed with a focus on user experience and aesthetics. It is structured to allow visitors to easily explore products, filter by categories, and enjoy a seamless shopping experience.

---

## ✨ Özellikler / Key Features

- 🛍️ **Ürün Kataloglama / Product Catalog:** Modern kart yapısı ve detaylı ürün görselleri. / Modern card layout and detailed product visuals.
- 📱 **Mobil Uyumlu Tasarım / Fully Responsive:** Tüm ekran boyutlarında kusursuz çalışan kullanıcı arayüzü. / User interface that works flawlessly across all screen sizes.
- ⚡ **Hızlı ve Akıcı Navigasyon / Fast Navigation:** JavaScript ile güçlendirilmiş dinamik geçişler ve etkileşimler. / Dynamic transitions and interactions powered by JavaScript.
- 🎨 **Modern UI/UX:** Minimalist renk paleti ve dikkat çekici tipografi tercihleri. / Minimalistic color palette and striking typography choices.

---

## 🛠️ Kullanılan Teknolojiler / Tech Stack

- **HTML5:** Semantik ve modern iskelet yapısı / Semantic and modern skeleton structure
- **CSS3:** Özel stiller, Flexbox/Grid sistemleri ve geçişler / Custom styles, Flexbox/Grid systems, and transitions
- **JavaScript (ES6+):** Dinamik arayüz özellikleri ve etkileşimler / Dynamic interface features and interactions
- **FontAwesome:** Profesyonel ikon entegrasyonu / Professional icon integration

## 🚀 Projeyi Çalıştırma / Getting Started

```bash
# Repository'yi klonlayın / Clone the repository
git clone https://github.com/merveayliz/apex-gear.git

# Proje klasörüne girin / Navigate to the project folder
cd apex-gear
```

### Yerel sunucu ile çalıştırma / Run locally

```bash
# Python ile yerel sunucu başlatma / Start a local server with Python
python -m http.server 8000
```

Ardından tarayıcıda şu adresi açın:

```text
http://localhost:8000
```
